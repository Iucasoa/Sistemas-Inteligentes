## Como executar

Cada pasta contém um notebook (`.ipynb`) e o relatório (`README.md`) com as análises.
Os notebooks podem ser abertos no Google Colab ou executados localmente:

```bash
pip install -r requirements.txt
```

Os datasets são obtidos automaticamente da UCI Machine Learning Repository dentro de cada notebook.
